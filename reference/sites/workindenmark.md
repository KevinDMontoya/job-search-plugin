# WorkInDenmark (https://www.workindenmark.dk/)

The Danish state's job portal for international candidates, with mostly English-friendly ads. Found-on dot: 🟢. Queue tab: "Queue – WorkInDenmark". Profile: `workindenmark-profile`.

## Searching
- Search the user's region from PROFILE.md. For Copenhagen, use the Capital Region; Bornholm is also in it, so include or exclude it by the user's commute.
- First backlog: the last month of ads, soonest deadline first, then by update time. Daily scan: ads published or updated in the scan window (see the daily-scan skill).
- Read the full ad before deciding.

## Applying
- Ads link to the employer's site or an email address.
- A WorkInDenmark account is optional (for saved jobs and a CV profile). The user creates it in the sign-in window (`open-login.ps1 -Site workindenmark`) if they want it.
