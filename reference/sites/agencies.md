# Staffing and temp agencies (Denmark)

Found-on dot: 🟤. Queue tab: "Queue – Agencies". One profile per agency: `<agency>-profile`, for example `adecco-profile`.

## Platforms
- Adecco (https://www.adecco.dk/)
- Randstad (https://www.randstad.dk/)
- Manpower (https://www.manpower.dk/)
- StudentConsulting (https://www.studentconsulting.com/)
- Other large agencies with jobs in the user's area that fit PROFILE.md.

## Searching
- Read the agencies' public job listings.
- In the Company column, write the agency name plus the client if it is stated.
- Agencies repost on Jobnet and Jobindex: check duplicates and mark 🔁.

## Applying and accounts
- Most agencies want a candidate profile before applying. 🚨 The user creates each profile in the sign-in window (`open-login.ps1 -Site <agency>`). If the agency is missing from the script, add it to `open-login.ps1` first.
- Until the profiles exist, queue the public ads, and send the user one message listing each agency's sign-up link and what the profile asks for.
- Agency consultants often answer by email or phone. The Gmail watcher logs those emails in the Responses tab.
