# This folder is the job-search plugin's source (public GitHub repo)

Sessions opened here maintain the plugin, they do not run a job search. Follow `MAINTAINING.md` for every change. Above all:
- Change the plugin only when the maintainer explicitly names the change to add. Never copy rules from the maintainer's own job-search setup on your own initiative: most of them are personal.
- Everything here is public. Never write personal data (names, contacts, addresses, ids, links, private paths). Personal rules belong in a user's own PROFILE.md.
- Run the privacy scan in `MAINTAINING.md` step 5 before every commit, and ask the maintainer before pushing.
- Bump the version in `.claude-plugin/plugin.json` with every change users should receive.
